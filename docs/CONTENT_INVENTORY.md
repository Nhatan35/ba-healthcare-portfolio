## 4. Minimum viable content release plan

This is a future content release sequence, not permission to implement or publish now.

| Gate | Required output | Exit condition |
| --- | --- | --- |
| R0 — facts and selection | Approved identity/focus, target roles/markets, public contact choice, safe CV facts, case evidence inventory. | All P0 personal inputs resolved; strongest relevant publishable case selected on evidence, not candidate order. |
| R1 — English content complete | English Home, About, Expertise section, Projects, selected case, Resume summary, Contact, metadata, and state/label copy. | Owner/BA review complete; all 19 case sections addressed honestly; essential artifacts and traceability present; no unresolved public placeholders or unsupported claims. |
| R2 — English release readiness | Later implementation/technical QA plus approved content; no Vietnamese option yet. | Separate implementation/publication authorization and actual accessibility, route/link, download, and SEO checks. Phase 2.1 does not satisfy this technical gate. |
| R3 — Vietnamese review | Vietnamese core pages, labels, metadata, resume summary, and selected featured narrative localized from the approved source revision. | Named reviewer/owner checks naturalness, fact parity, terminology, artifacts, privacy, and links. Other English-only cases explicitly labeled. |
| R4 — Vietnamese activation | Release-ready reviewed Vietnamese core set with equivalent-page mappings. | All activation criteria in localization strategy and future technical checks pass; then enable language choice through an authorized release. |
| R5 — expand on evidence | Additional verified real or clearly labeled simulated cases; optional PDFs/feedback. | Each addition independently passes provenance, contribution, privacy, analytical quality, and locale gates. |

Complete English content first; review Vietnamese before activating it. One strong verified case is preferable to three unsupported stories. A verified simulation means its origin/authorship and analysis are confirmed, not that it was professional employment. If no case passes the gate, keep the intended evidence-led release blocked and resolve scope with the owner; do not fabricate artifacts or claim completed content.

An approved English PDF is useful but not required if the public HTML resume is complete; a Vietnamese PDF is optional. No public page should offer a missing download. A reviewed Vietnamese core narrative is required for the selected lead case even when some supporting artifacts remain labeled English originals.
